# Veloretti

A responsive multi-page website for the Veloretti electric bike brand, created as a frontend portfolio project. The website features a clean modern interface, smooth animations, interactive product pages, and a fully responsive user experience across all devices.

## Features

- Responsive multi-page layout;
- Mobile-first approach;
- Semantic HTML5 markup;
- Accessibility support (aria-\*, keyboard navigation, focus states);
- Interactive product catalog and product pages;
- Swiper sliders with custom navigation;
- GSAP animations and visual effects;
- Lazy-loaded responsive WebP images;
- SEO-friendly meta tags and Open Graph support;
- Optimized production build with Vite.

## Tech Stack

- HTML5
- SCSS (BEM)
- Vanilla JavaScript (ES Modules)
- Vite
- Swiper
- GSAP
